Today when I tried to push a local repo to a new remote repo on github, I encountered a 403 error where I could not push my local branch to remote.<!--more--> 
After taking a closer look, I noticed the whole time I was trying to push via HTTPS instead of SSH, while my local machine is set up via SSH keys.

Screenshots for the culprit action:
![HTTPS option]({{ site.baseurl }}/assets/images/posts/github-push-403/https-1.png)
![HTTPS option code]({{ site.baseurl }}/assets/images/posts/github-push-403/https-2.png)

Screenshots for the action I should have taken:
![SSH option]({{ site.baseurl }}/assets/images/posts/github-push-403/ssh-1.png)
![SSH option code]({{ site.baseurl }}/assets/images/posts/github-push-403/ssh-2.png)

Choose SSH!
